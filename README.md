# Advance Tera Video Bot — Phase 1 (Render Fixed)

This is the clean Phase 1 foundation for a Render Web Service.

## What works in Phase 1

- Render-compatible webhook mode
- `/start` command
- Professional welcome message
- Optional welcome meme image
- No TeraBox resolver code yet

## Project structure

```text
advance-tera-video-bot/
├── assets/
│   └── welcome.jpg
├── bot/
│   ├── __init__.py
│   └── handlers.py
├── main.py
├── requirements.txt
└── README.md
```

## Render

### Build Command

```text
pip install -r requirements.txt
```

### Start Command

```text
python main.py
```

### Required Environment Variable

```text
BOT_TOKEN=your_telegram_bot_token
RENDER_EXTERNAL_URL=https://your-service-name.onrender.com
```

Optional:

```text
WEBHOOK_PATH=telegram-webhook
```

Render automatically provides:

```text
PORT
```

Do not manually create a PORT variable unless you have a specific reason.

## Welcome image

Put your own funny meme at:

```text
assets/welcome.jpg
```

No image is generated by this project.

If `welcome.jpg` is missing, `/start` safely sends the welcome text only.
