# Bot modules

- `config.py` — environment configuration
- `database.py` — SQLite users, request logs, rate limits and history
- `platforms.py` — supported link detection
- `resolver.py` — TeraBox resolution and fallback chain
- `keyboards.py` — Telegram keyboards
- `handlers.py` — commands, link processing, history and admin UI
- `main.py` — Render webhook startup
